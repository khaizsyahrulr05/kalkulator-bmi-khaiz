# Kalkulator BMI

Aplikasi sederhana untuk menghitung BMI

## Fitur
- Menghitung nilai BMI
- Menampilkan kategori BMI
- Input berat badan (kg) dan tinggi badan (cm)

## Rumus BMI

BMI = Berat Badan (kg) / Tinggi Badan (m)²

## Kategori BMI

< 18,5 = Underweight 
18,5-24,9 = Normal
25 - 29,9 = Overweight
≥ 30 = Obesitas

## Cara Menjalankan
1. Clone repository ini.
2. Buka project menggunakan Apache NetBeans.
3. Jalankan project melalui NetBeans.
